# SIMPLE-CALCULATOR

A simple command-line calculator written in C.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero checking
- Supports decimal numbers
- Handles invalid operators

## Requirements

- A C compiler such as GCC

## Compile

```bash
gcc calculator.c -o calculator
```

## Run

On Linux or macOS:

```bash
./calculator
```

On Windows:

```bash
calculator.exe
```

## Example

```text
Enter expression (e.g. 5 + 3): 5 + 3
= 8.00
```
